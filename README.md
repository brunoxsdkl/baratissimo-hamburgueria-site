# Baratíssimo Hamburgueria

Site estático publicado na Vercel a partir deste repositório.

O cardápio visível foi transcrito em 15/11/2026 da página pública da unidade **Brutus Baratíssimo – Centro** na 99Food, conforme pedido. São 34 ofertas e 23 fotos distintas. O endereço e contato do site são da unidade Jardim das Américas. Os preços da unidade Centro podem divergir; por isso o site orienta confirmação pelo WhatsApp antes do pedido. Não há links de saída para marketplaces no site.
